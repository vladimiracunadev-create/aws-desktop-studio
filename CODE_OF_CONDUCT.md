# 🤝 Código de conducta

[**← README**](README.md) · [**🛠️ Contribuir**](CONTRIBUTING.md) · [**🔒 Seguridad**](SECURITY.md)

> [!IMPORTANT]
> Colaboramos con respeto, evidencia técnica y protección activa de los datos sensibles.

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Se espera una colaboración respetuosa, técnica y centrada en evidencia. Conductas abusivas, discriminatorias o que expongan datos sensibles no son aceptables.

Para reportar una situación de conducta, usa de forma privada el canal de contacto indicado en el perfil de GitHub del mantenedor. Para vulnerabilidades, sigue [SECURITY.md](SECURITY.md) y no abras un issue público.

| Situación | Canal correcto |
|---|---|
| Duda o propuesta técnica | Issue o Discussion |
| Conducta inapropiada | Contacto privado del mantenedor |
| Vulnerabilidad | Reporte privado según `SECURITY.md` |
| Credencial expuesta | Revocación inmediata y reporte privado; nunca issue público |
