## Organizaciones
AWS Organizations estructura cuentas y aplica Service Control Policies.

## Control Tower
Landing zone y guardrails para gobierno multi-cuenta.

## WAF / Shield
Protección en capa de aplicación y mitigación DDoS según servicio/nivel.

## GuardDuty / Security Hub / Inspector
Detección de amenazas, agregación de findings y análisis de vulnerabilidades/cargas compatibles.

## CloudTrail / Config
Auditoría de llamadas y evaluación/historial de configuración.
