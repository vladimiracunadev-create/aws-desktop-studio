# Amazon S3

Almacenamiento de objetos altamente durable. Organiza datos en buckets y keys.

## Usos
Backups, archivos, contenido estático, data lakes, logs y artefactos.

## Características
Versioning, lifecycle, replication, Object Lock, cifrado, policies, access points y clases de almacenamiento.

## Seguridad
Bloquea acceso público salvo necesidad explícita. Usa IAM/bucket policies cuidadosamente y cifrado. No confundas S3 con filesystem POSIX.

## App
La v0.1 lista buckets. El roadmap agrega navegación por prefijos/objetos, metadata y operaciones de carga/descarga controladas.
