# Soporte

- Preguntas de uso y propuestas: abre un GitHub Discussion o issue con pasos reproducibles.
- Fallos: incluye versión de Windows, Node.js, AWS CLI, comando `pnpm run verify` y mensaje redactado.
- Seguridad: sigue [SECURITY.md](SECURITY.md); no publiques credenciales, Account IDs, ARN ni respuestas completas de AWS.

Este proyecto comunitario se mantiene sin SLA. Los problemas de facturación, IAM o disponibilidad del servicio deben verificarse también con la documentación y soporte oficial de AWS.
