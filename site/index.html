CAPACIDADES

Una cabina de trabajo, no otra consola infinita.

Diseñada para confirmar contexto, consultar primero y operar solo cuando la intención es inequívoca.

01

Conexión local

Detecta perfiles existentes, inicia SSO y valida la identidad efectiva con STS. Las credenciales siguen bajo AWS CLI.

02

Exploración legible

EC2, S3, Lambda, RDS, DynamoDB, VPC, IAM, observabilidad, contenedores, integración y costos en una vista coherente.

03

Aprendizaje en contexto

Veinte tutoriales conectan cada pantalla con arquitectura, permisos, costos y prácticas de laboratorio.

SEGURIDAD POR DISEÑO

La fricción correcta, en el momento correcto.

El renderer está aislado, el shell permanece fuera del flujo y cada cambio real necesita dos decisiones humanas visibles.

  1. 01
    Lectura por defectoLa aplicación inicia sin capacidad mutable habilitada.
  2. 02
    Allowlist cerradaComandos, acciones, protocolos e identificadores se validan.
  3. 03
    Confirmación nativaEC2 start/stop/reboot exige modo operativo y diálogo final.
  4. 04
    Cadena verificableCI, auditoría npm, CodeQL, SBOM y checksums por release.
INICIO RÁPIDO

De cero a la aplicación validada.

Necesitas Windows, Node.js 22, AWS CLI v2 y un perfil configurado.

git clone https://github.com/vladimiracunadev-create/aws-desktop-studio.git
cd aws-desktop-studio
npm ci
npm run verify
npm start
ALCANCE HONESTO

Operativo donde lo afirma. Documentado donde todavía no.

La aplicación consulta 16 servicios reales. Otros 12 módulos son educativos. No crea infraestructura, no reemplaza IAM y sus binarios comunitarios aún no tienen firma comercial.
